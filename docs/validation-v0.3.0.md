## 验证内容

1. 原有计时开始、暂停、刷新、继续、到期与任务锁定；专注只记一次，休息不增加完成记录。
2. 第一版计时与记录迁移；第二版设置、音效与历史上传 SQLite，刷新和再次同步不重复。
3. 完成一分钟专注后，通过真实 API 查询落库结果；独立浏览器上下文不共享 localStorage，也能读取同一条历史。
4. GET 失败时保留旧本地记录；POST 失败时计时继续、刷新保留待同步记录，恢复请求后上传成功且不重复。
5. 旧存档 emoji 截断和孤立代理字符经规范化后，Go 回传内容一致，同步确认成功；刷新仍只有一条。
6. 服务端历史搜索、分页、真实 CSV 下载、中文引号与任务文本安全显示。
7. 前端同步请求重入、超时、响应丢失、非法响应，以及请求期间新增记录的串行上传。
8. 远端已有 1000 条时，较旧本地记录先上传再裁剪视图；上传失败不提前合并；请求期间本地视图替换也分批上传原快照。
9. SQLite 实际重复上传去重、服务重建后读取、整批事务回滚、最新 1000 条排序与数据库总数。
10. Go 请求体上限、批量上限、非法字段、重复 JSON 字段、UTF-16 长度、同源 Origin 与本机 Host 限制；静态白名单不暴露数据库和 .git。
11. 存储不可用仍可计时；多标签旧页冻结与写入前快照检查继续有效。
12. Web Audio 节点、音效开关持久化、键盘操作、手机布局，无 pageerror 或横向溢出。
13. 直接打开 HTML 时明确显示纯本地模式，不发送不存在的 API 请求，完成计时与刷新仍保留记录。

## 检查中修复的问题

- 首轮有四项浏览器案例因测试使用的离线文案正则不匹配而失败。改为校验实际 offline 状态和一条待同步记录，最终完整运行通过。
- 本地先合并远端再裁剪会遗漏较旧未上传记录。改为保留请求前快照，全部上传确认后再更新视图，并增加超过 1000 条边界回归。
- 任务字符串按 UTF-16 切片会切开 emoji，Go 解码后的内容变化会导致确认失败。改为按码点截断、修复旧存档孤立代理字符，并统一整数毫秒时间戳。
- 仅校验 Origin 与 Host 相等不足以隔离任意域名访问。增加所有请求的本机 Host 白名单，恶意 Host 即使 Origin 一致也返回 403。

## 验证边界

手机是浏览器视口与触摸模拟，未在实体手机上测试。音效验证了真实 Web Audio 节点和静音控制，未听取实体扬声器输出。

本版只监听本机，没有公网、账号或外部设备接入验证。数据库保存已同步的全部历史，页面/API 列表最多展示最近 1000 条；离线未上传的历史也受浏览器缓存上限约束。计时和设置不会在不同浏览器之间同步，同一浏览器来源仍建议单页计时。
